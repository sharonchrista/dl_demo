# Deep Learning Visual Lab

Interactive teaching demo for understanding the arithmetic inside basic deep learning models.

## Modules

- **ANN** — random initialization, detailed forward propagation, loss, backpropagation, gradients, per-weight updates, and epoch history.
- **CNN** — editable 6×6 teaching images for digits 7 and 9, editable 3×3 convolution kernel, step-by-step multiplication/summation, ReLU, max/average pooling, flattening, and a tiny softmax classifier.
- **RNN** — editable 6-row sequence dataset, shared recurrent weights, hidden-state calculation for every row/time step, final prediction, Backpropagation Through Time (BPTT), accumulated gradients, and epoch-by-epoch shared weight updates.

The application is completely static: no Python server or backend is required.
